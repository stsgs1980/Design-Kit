# Design Kit: отчёт по стеку и дизайн-фичам

Справочник Design Kit, собранный по мотивам Magic UI Pro — **Codeforge**. Оригинал: <https://pro.magicui.design/docs/templates/codeforge>,
живая витрина: <https://codeforge-magicui.vercel.app/>. Задача была не «скопировать картинку», а разобрать
механики: что даёт эффект «дорого», сколько это стоит в килобайтах и кадрах, и как это собрать без
дизайнерских библиотек.

Всё измерено на прод-сборке (`next build && next start`), Chromium 131, вьюпорт 1440×900, DPR 2.

## 3. Дизайн-система

### 3.1 Токены и тема — один источник: класс на `<html>`

Значения объявлены **один раз** через `light-dark()`, а какое взять — решает `color-scheme`:

```css
:root {
  color-scheme: light dark; /* по умолчанию — системная тема */
  --background: light-dark(#f9fafb, #09090b);
  --foreground: light-dark(#0a0a0a, #fafafa);
  --border: light-dark(#e5e5e5, rgb(255 255 255 / 0.1));
  /* цвет внутри тени тоже light-dark() — вся тень остаётся одной строкой */
  --shadow-badge: 0 0 0 1px light-dark(rgb(0 0 0 / 0.08), rgb(255 255 255 / 0.08)), …;
}
.light {
  color-scheme: light;
}
.dark {
  color-scheme: dark;
}
```

Тему выбирает **сервер**: `app/layout.tsx` читает cookie и ставит класс на `<html>`. Класс всегда
явный — тёмная тема по умолчанию, поэтому страница не зависит от настройки ОС и от того, дошла ли
cookie.

```tsx
const stored = (await cookies()).get("theme")?.value;
const theme = stored === "light" ? "light" : "dark";

return (
  <html lang="ru" className={theme} suppressHydrationWarning>
    {children}
  </html>
);
```

Отсюда три свойства: **нет вспышки** (класс приезжает в HTML), **нет рассинхрона** (у `<html>` нет
инлайнового `style` — React сверяет атрибуты со своей разметкой, и лишний атрибут считает ошибкой),
**цвет-схема из класса** (`.light` / `.dark`). Иконки тумблера — тоже CSS по `color-scheme`
(`.theme-sun` / `.theme-moon`), поэтому кнопка корректна до гидрации.

Выбор человека дублируется в `localStorage` и применяется загрузочным скриптом **до первой
отрисовки**: в песочнице превью cookie не сохраняется между страницами. Скрипт меняет только класс,
поэтому `<html>` помечен `suppressHydrationWarning`: когда localStorage и cookie разошлись, побеждает
DOM (приём Next.js для тем), и React не рапортует рассинхрон.

### 3.2 Типографика

- заголовки: `tracking-tighter` (−0.05em) + `text-balance` — строки рвутся по смыслу, а не по ширине;
- шкала адаптивная, без «прыжков»: `text-3xl → md:text-4xl → lg:text-6xl`;
- моно-шрифт — только для кода, чисел и технических подписей (`font-mono text-[11px]`);
- `font-feature-settings: "ss01"` глобально — альтернативные глифы Geist.

### 3.3 «Хайрлайн»-сетка (главный приём шаблона)

Вместо теней и карточек-островов — линии в 1 пиксель, которые делят страницу как чертёж:

- `divide-x` / `divide-y` по сеткам секций (`md:divide-x`);
- `CornerPlus` — 8 микродивов с negative-offset'ами (`-top-px -left-3`), из-за чего «узлы» соседних
  секций стыкуются крестиком;
- линейки таймлайна `h-px w-screen origin-left` — линия выходит за контейнер и обрезается `overflow-x-hidden`.

### 3.4 Маски вместо обрезки

Правило проекта: **любой фон подключается с `mask-image`**. Обрезка бордером даёт «плитку», маска — «дыхание».

```css
mask-image: radial-gradient(ellipse 70% 60% at 50% 10%, white, transparent);
mask-image: radial-gradient(ellipse at center, black 55%, transparent 88%); /* карта */
mask-image: linear-gradient(to bottom, transparent 0%, black 100%); /* свечение hero */
```

Плюс `.mask-x` / `.mask-y` в `globals.css` — для лент.

### 3.5 Прочие атомы

| Атом            | Что делает                                                    |
| --------------- | ------------------------------------------------------------- |
| `GradientText`  | радиальный градиент из двух токенов + `background-clip: text` |
| `HeaderBadge`   | пилюля секции с «объёмной» тенью `--shadow-badge`             |
| `SectionHeader` | единый ритм: `p-6 md:p-24`, `max-w-lg`, по центру             |
| `CornerPlus`    | соединительные крестики на стыках секций                      |
| `NoiseTexture`  | зерно `feTurbulence` поверх градиентов — лечит banding        |

## 4. Фичи и эффекты по секциям

### 4.1 Hero — 0 КБ JS

- **DotPattern**: SVG `<pattern>` + `<circle>`, цвет `currentColor`, прозрачность 0.18, маска радиальная.
- **Два свечения**: широкий радиальный градиент + тот же, но плотнее и с `blur(50px)` — даёт «дымку»,
  а не плоское пятно. Оба срезаны `mask-image: linear-gradient(...)`.
- **Кнопки**: primary залита `var(--primary)`, secondary — стеклянная с хайрлайном.

### 4.2 Sticky workflow — «кино» на таймерах

- Левая колонка: `md:sticky md:top-20` **обязательно** вместе с `md:self-start` в grid-ячейке (иначе не липнет).
- Справа два демо, которые играют сами: статус-пилюля + окно терминала (шаги 400 → 1400 → 800 → 800 → 600 мс)
  и дифф-карточка (клик по кнопке → правка «применяется», `height` анимируется, `margin` компенсирует).
- `useInView(once: false)` — ушли из вьюпорта, таймлайн сбросился и проиграется заново.
- `AnimatePresence` + `mode="wait"` на пилюле: смена статуса без наложения двух подписей.
- Сдвиг карточки — `animate={{ x: "18%", y: "-44%" }}` со spring; на мобильном смещения меньше (`use-is-mobile.ts`).

### 4.3 Dither — единственный WebGL, и он честно ленивый

Два прохода на голом WebGL 1:

1. **FBM-шум** → фреймбуфер: симплекс 2D, 4 октавы `abs(noise)`, амплитуда с затуханием,
   `p2 = p - time*speed` даёт «плывущий» рисунок; мышь вычитает `0.5` в радиусе `mouseRadius`.
2. **Пост-проход** по текстуре: матрица Байера 8×8 (0…63/64) как карта порогов,
   `color += (bayer - 0.25) * step`, затем квантование `floor(c*(colorNum-1)+0.5)/(colorNum-1)`.

Инженерные решения вокруг:

- `dynamic(..., { ssr: false })` + `useInView(rootMargin: 200px)` — чанк грузится только у вьюпорта;
- CSS-подложка показывается до монтирования и если WebGL недоступен;
- `preserveDrawingBuffer: true` и синхронный кадр после `resize` — иначе при скриншоте/ресайзе canvas пустой;
- DPR ограничен 2 — на retina 3× проход по пикселям дороже, чем заметна разница;
- `prefers-reduced-motion` → rAF не запускается, остаётся статичный кадр;
- `WEBGL_lose_context` намеренно не вызывается: при повторном монтировании контекст вернулся бы
  уже потерянным, и canvas остался бы чёрным;
- цвета берутся из CSS-переменных (`--gradient-primary`, `--background`), смена темы ловится
  `MutationObserver` на `documentElement.class`.

Формулы, без которых картинка рассыпается:

```glsl
// порог из матрицы Байера, посчитанной процедурно:
// bayer2 = [[0,2],[3,1]], bayer8 = сумма bayer2 по трём уровням / 64
float threshold = bayer8(scaledCoord) - 0.25;
color += threshold * (1.0 / (colorNum - 1.0));

// квантование до colorNum уровней
color = floor(color * (colorNum - 1.0) + 0.5) / (colorNum - 1.0);
```

Ленивая обёртка (`components/kit/dither/lazy-dither.tsx`):

```tsx
const Dither = dynamic(() => import("./dither").then((m) => m.Dither), { ssr: false });

/** Клиентская обёртка: WebGL-эффект грузится только при появлении в вьюпорте. */
export function LazyDither(): ReactElement {
  const ref = useRef<HTMLDivElement>(null);
  const inView = useInView(ref, { margin: "200px", once: true });

  // до inView — только CSS-градиент-заглушка; после — чанк и плавное opacity 0 -> 1
  return <div ref={ref}>{inView ? <Dither /> : <div className="dither-placeholder" />}</div>;
}
```

### 4.4 Coverage — серверная карта из точек

Конвейер целиком на сервере:

1. `lib/world-geo.json` — 130 стран, GeoJSON упрощён Дугласом-Пекером (eps 1.5) до **14.6 КБ**;
2. `lib/world-map.ts` — проекция Меркатора (`mercX/mercY`) и обратная к ней, even-odd ray casting
   («точка в полигоне»), сетка `√(samples × aspect)` с гексагональным сдвигом чётных строк;
3. `buildDottedMap()` кэшируется в модульном `Map` по ключу `WxH:samples` — считается один раз;
4. в HTML уезжают **1400 готовых `<circle>`**, на клиенте **ноль** JS;
5. маркеры городов — через `projectPoint()` (та же математика, иначе точки «уедут» относительно городов);
6. `RadialOrbit` рядом: лучи по 360/N градусов, `scaleX` от центра, иконки на полярных координатах,
   выстреливаются spring-ом с задержкой.

### 4.5 Отзывы — лента на чистом CSS

- трек дублируется **три** копии (не две — см. §8) и анимируется `translateX(calc(-100% - var(--gap)))`;
- копии отмечены `aria-hidden`, длительность — CSS-переменная `--duration` (52 s и 64 s, вторая лента `reverse`);
- пауза — `group-hover:[animation-play-state:paused]`, ноль JS;
- края гасятся маской `.mask-x`, карточки — `figure` + `blockquote` + `figcaption`;
- `prefers-reduced-motion: reduce` → `animation-play-state: paused`.

### 4.6 Библиотека паттернов (`components/kit/`)

| Компонент        | Техника                                                   | Где уместен                  | Цена                 |
| ---------------- | --------------------------------------------------------- | ---------------------------- | -------------------- |
| `DotPattern`     | SVG `<pattern>` + `<circle>`, `currentColor`              | фон hero, пустые состояния   | ~1 КБ, 0 JS          |
| `StripedPattern` | `<pattern>` c `rotate(45)`                                | тонкие разделители           | ~1 КБ, 0 JS          |
| `NoiseTexture`   | `feTurbulence` + `saturate 0` + `feComponentTransfer`     | поверх градиентов, дарк-тема | 0 JS                 |
| `LightRays`      | **два** слоя `conic-gradient` + маска + `blur` + `screen` | CTA, «прожектор»             | 0 JS, GPU            |
| `FlickeringGrid` | Canvas 2D, `Float32Array` прозрачностей                   | подсветка активного таба     | rAF, DPR ≤ 2         |
| `GlyphMatrix`    | Canvas 2D, `Uint16Array` индексов глифов                  | «терминал», пустые состояния | `setInterval`        |
| `Marquee`        | CSS keyframes, 3 копии, маска                             | отзывы, логотипы             | 0 JS                 |
| `WorldMap`       | GeoJSON → точки на сервере                                | «мы везде»                   | 0 JS, 14.6 КБ данных |
| `RadialOrbit`    | полярные координаты + spring                              | интеграции, экосистема       | framer-motion        |
| `Dither`         | WebGL, 2 прохода                                          | акцентная полоса             | ленивый чанк         |

Замеры по ходу отбора:

- **LightRays**: один слой `conic-gradient` после `blur` почти невидим (тонкие лепестки сливаются).
  Помогло разделение на мягкий слой (`blur 18px`, opacity .85) и яркое ядро (`blur 5px`, `mix-blend-mode: screen`),
  10 лучей, alpha ≥ .75.
- **NoiseTexture**: на DPR 2 `baseFrequency 0.3` — крупная плёнка, 0.5–0.7 — мелкое зерно,
  **≥ 0.9 на экране не читается**. Дефолт — 0.65.
- **GlyphMatrix**: мутация ~4% ячеек каждые 90 мс, а не каждый кадр — визуально то же, CPU в разы меньше.

### 4.7 Шапка справочника и документная сетка

Шапка — серверный компонент (`components/nav/site-header.tsx`), одна на всех страницах: логотип,
пять разделов каталога, ссылка на стену паттернов, переключатель темы и кнопка «Открыть кит».
Разделы — это адреса состояния каталога (`#catalog`, `#where`, `#c-hero-recipe`, `#matrix`, `#rules`),
а не отдельные страницы, поэтому навигация не перезагружает документ.

Внутристраничные ссылки — нативные `<a>`: `next/link` со строкой `#...` дописывает hash к текущему
(`#rules#c-hero-recipe`) и не шлёт `hashchange`, из-за чего каталог не переключался. Адреса в шапке
абсолютные (`/#catalog`): тот же пункт обязан работать со стены кита и стены паттернов.

Сетка полотна — «хайрлайн» вместо карточек: `max-w-[1400px]`, разделы через `border-b`, заголовки
групп крупнее подписей, липкая шапка с `bg-background/85 backdrop-blur-md`.

Одна сетка на всех страницах: главная, гид, стена кита и стена паттернов держат один контейнер
`1400 px` с отступом `24 px` (было `1240`: на 1920 оставалось по 340 px пустого поля).

До этого стены жили на `1152` и `1024`, и при переходе контент прыгал вправо на 52 и 116 px
относительно шапки — страница читалась как другая вёрстка. Держит проверка «левый край заголовка
совпадает с логотипом» в `verify:effects`.

Шкала зафиксирована и проверяется машинно (`checkScale`):

| Ширина окна | Контейнер | Сайдбар каталога | Стена кита  | Абзацы                |
| ----------- | --------- | ---------------- | ----------- | --------------------- |
| 390-1024    | до краёв  | лента чипов      | 1-2 колонки | полная ширина колонки |
| 1280        | 1280      | 300              | 3 колонки   | `max-w-[68ch]`        |
| 1440        | 1400      | 300              | 3 колонки   | `max-w-[68ch]`        |
| 1680-1920   | 1400      | 300              | 4 колонки   | `max-w-[68ch]`        |

Мера строки живёт отдельно от ширины контейнера: заголовки занимают контейнер, абзацы — `68ch`,
иначе на 1920 строка становится нечитаемой.

### 4.8 Гид по комбинированию — `/guide`

Страница `/guide`: лестница стоимости (SVG → CSS → Canvas2D → WebGL), шесть правил комбинирования
(один фон-герой, маска вместо обрезки, контраст, одна анимация на секцию, цвет из токена, честная
цена), живой пример «собрать hero из трёх слоёв», таблица «эффект → место → цена» и чеклист перед
мержем. Каталог (`/#catalog`) отвечает «что взять», `/guide` — «как это совместить».

## 5. Правила, по которым эффекты комбинируются

Всё это же лежит в гайде `/guide`, но коротко:

1. **Лестница стоимости**: SVG → CSS-градиент → Canvas 2D → WebGL. Поднимайся, только если предыдущая
   ступень не решает. 90% лендингов живут на первых двух.
2. **Один фон — один герой**: максимум два фоновых слоя (большой + микро). Третий — шум, который спорит с текстом.
3. **Маска вместо обрезки** — самый дешёвый признак аккуратной работы.
4. **Контраст**: фон ≥ 3× тише контента. Прищурился — первым читается заголовок, а не паттерн.
5. **Одна анимация на секцию**: лента едет — всё остальное статично.
6. **Цвет из токена** (`currentColor` / `var(--primary)`) — дарк-тема работает бесплатно.
7. **Честная цена**: считай КБ, кадры и батарею, а не «красиво».

## 8. Грабли, которые реально выстрелили (и как вылечены)

| Симптом                                                    | Причина                                                                                                                          | Решение                                                                                |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `Encountered a script tag while rendering React component` | React 19 ругается на **любой** `script`, созданный на клиенте; `<Script>` из next/script внутри делает `createElement('script')` | тема переехала в cookie, а оставшийся скрипт — серверный `dangerouslySetInnerHTML`     |
| `A tree hydrated but some attributes…` на `<html>`         | загрузочный скрипт писал `style.colorScheme` — на `<html>` появлялся атрибут, которого нет в разметке React                      | `color-scheme` из класса (`.dark` / `.light`) + `suppressHydrationWarning` на `<html>` |
| `npm run lint` красный на своём же тексте                  | в подсказке про песочницу стоял символ `↗` — юникод-политика репозитория его запрещает                                           | текст вместо стрелки: «иконка внешней ссылки»                                          |
| `Hydration failed…` на карте, 1400 ≠ 1400 точек            | секция была `"use client"` → точки считались и на сервере, и в браузере, результаты разошлись                                    | секция серверная, клиентским остался только RadialOrbit                                |
| Карта из 66 точек вместо 1400                              | обратная проекция Меркатора не была обратной к прямой (`/π·180` в одну сторону)                                                  | `mercX/mercY` и строго обратные к ним                                                  |
| Лента «рвётся» пустотой на 1600+                           | при 2 копиях сдвиг на копию бесшовен, только если копия ≥ окна (1488 < 1920)                                                     | 3 копии: непрерывность при `copy ≥ (W − gap)/(repeat − 1)`                             |
| Coverage «развалилась» на пустые колонки                   | `col-span-4` без `md:` в `grid-cols-1` создаёт неявные колонки                                                                   | `md:col-span-4/2`, `min-w-0`; при недогруженном CSS секция складывается в одну колонку |
| Шапка и sticky-заголовок вылезали на 768                   | русский текст длиннее английского                                                                                                | меню с `lg`, `shrink-0` + `whitespace-nowrap`, `[overflow-wrap:anywhere]`              |
| Canvas пустой на скриншоте                                 | при ресайзе фреймбуфер обнуляется                                                                                                | синхронный кадр после `resize`, `preserveDrawingBuffer: true`                          |
| Sticky-колонка «не липнет»                                 | `md:sticky` в grid-ячейке без `md:self-start` не работает                                                                        | `md:self-start` на самой колонке                                                       |
| Демо «одноразовое»: автоплей не повторяется                | `useInView` с `once: true` гасит наблюдатель после первого появления                                                             | `once: false` + сброс состояния                                                        |
| WebGL падает на сервере (`document is not defined`)        | код шейдера импортируется в серверный компонент                                                                                  | `dynamic(..., { ssr: false })` вокруг эффекта                                          |
| `mask-image` не работает в Safari                          | нужен `-webkit-mask-image`                                                                                                       | оба свойства прописаны рядом                                                           |
| Цвет из `color-mix()` терялся при сборке классов           | значение жило в Tailwind-классе и не попадало в итоговый CSS                                                                     | инлайн-стиль: читается Tailwind-агностично                                             |
| `AnimatePresence mode="wait"` «не успевает»                | exit длится дольше ожидания в тесте                                                                                              | паузы 500–600 мс в проверках                                                           |

## 11. Как расширять библиотеку паттернов (гайд для следующего исполнителя)

### 11.1 Критерии приёмки нового эффекта

Эффект попадает в `components/kit/`, только если проходит все пункты:

1. **Ноль новых зависимостей.** Разрешено: SVG, CSS, Canvas 2D, WebGL. Запрещено тянуть `three`, `gsap`, `lottie`.
2. **Лестница стоимости соблюдена**: сначала SVG → потом CSS-градиент → потом Canvas 2D → и только потом WebGL.
3. **Детерминированный рендер.** Никаких `Math.random()` / `Date.now()` в разметке: иначе React отдаст
   `Hydration failed…`. Случайность — только внутри `useEffect`/`requestAnimationFrame` (после гидрации).
4. **Фон — с маской**, иначе конкурирует с текстом. Цвет — `currentColor` или токен.
5. **Анимация** — только `opacity`/`transform`; всё, что дороже, живёт в Canvas и гасится `IntersectionObserver`.
6. **`prefers-reduced-motion`** — пауза или статичный кадр.
7. **Бюджеты**: CSS ≤ 60 КБ raw, JS приложения +≤ 10 КБ gzip, ни одного кадра дольше 8 мс на 1440×900.
8. `./node_modules/.bin/tsc --noEmit` чисто, `next build` зелёный, `npm run verify:effects` без падений.

### 11.2 Куда что класть

- `components/kit/<id>/<id>.tsx` — сам эффект, пропсы по образцу соседей (`className`, цвет, плотность);
- `components/kit/<id>/<id>.demo.tsx` — демо-сцена рядом, плюс прогон `npm run kit:registry`;
- демонстрация — каталог `components/guide/catalog/` (вкладки «кит / паттерны», сайдбар и паспорт выбранной записи);
- общая теория — таблица «эффект → техника → место → цена» в `app/guide/page.tsx`;
- строки в `REPORT.md` §4.6 и `README.md` §4 — обязательны, иначе библиотека снова станет «набором демок».

### 11.3 Состав библиотеки

Полный разбор всех **77 компонентов Magic UI** (что берём, что адаптируем, что отклоняем и почему),
итоговый состав кита, матрицы совместимости и спецификация реализации — в **[`docs/KIT.md`](./docs/KIT.md)**.
Коротко: 27 берём (10 уже есть), 19 адаптируем, 31 отклоняем; кит строится четырьмя фазами,

Решения, которые видно в коде:

1. **Фильтры живут в URL**, а не в `useState`: `/kit?cat=surface&tech=css`. Страница остаётся
   серверной, состояние фильтра можно переслать ссылкой, ноль клиентского JS на индексе.
2. **Манифест — единственный источник правды**: карточки, страницы компонентов, статистика в шапке
   и проверки читают одни и те же записи. Числа в шапке `/kit` считаются, а не пишутся руками.
3. **`verify-kit.mjs` сверяет четыре источника**: папки `components/kit/<id>/`, файлы
   `<id>.tsx` / `<id>.demo.tsx`, записи манифеста и упоминания в `docs/KIT.md`. Плюс обратное
   направление: папка без записи — ошибка, а не «потом добавим».
4. **Реестр демо генерируется** (`npm run kit:registry`) обходом папок, а `verify:kit` запускает его
   с `--check`: расхождение ловится, а не правится руками.
5. **Один компонент — два режима вместо двух компонентов**: `BorderBeam` покрывает и Border Beam,
   и Shine Border из Magic UI.
6. **Все декоративные слои гасятся** при `prefers-reduced-motion`; блок правил стоит последним в
   `app/globals.css`, иначе базовые правила перебивали бы `animation: none`.

### Главная — витрина кита

Раньше кит жил отдельной страницей, а главная повторяла те же эффекты своим кодом. Теперь главная
сама показывает состав кита: каталог из 22 карточек стоит сразу под первым экраном, и с
него видно, какие компоненты есть и как они называются.

| Секция      | Компоненты кита                                                   |
| ----------- | ----------------------------------------------------------------- |
| `#hero`     | WorldMap (фон), LightRays, NoiseTexture, BorderBeam, TerminalDemo |
| `#catalog`  | KitCard x20 — живые демо, имя, техника, цена в JS из манифеста    |
| `#showcase` | Dither на всю ширину, ProgressiveBlur, NoiseTexture               |
| `#process`  | MagicCard x2 (терминал и диф)                                     |
| `#reviews`  | Marquee x2, GlareHover                                            |
| `#cta`      | StripedPattern, LightRays                                         |

Почему это не декорация:

1. **Подпись ячейки берётся из манифеста** (`cell.tsx` -> `getKitEntry`): имя и цена в JS не могут
   разойтись с каталогом.
2. **Числа считаются по манифесту** (`kitEntries.length`, фильтр `cost.js === "0"`), поэтому новая
   фаза меняет главную без правок в разметке.
3. **`where` в манифесте обновлён** — у компонентов указаны реальные ячейки, а не только `/kit`.
4. **`verify:effects` проверяет каркас**: шесть ячеек `main section[id]` и шесть плиток со ссылками
   на `/kit/<id>`.
