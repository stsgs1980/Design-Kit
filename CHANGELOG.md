# Changelog

Формат — [Conventional Commits](https://www.conventionalcommits.org/), профиль `angular`
([Keep a Changelog](https://keepachangelog.com/ru/1.1.0/) по структуре).

Файл генерируется командой `npm run changelog`; вручную правятся только версии и даты.

## [1.0.0] - 2026-10-26

### Features

- кит из 22 компонентов с паспортами: демо, пропсы, состояния, доступность и места применения
- 17 паттернов уровня страницы, собранных только из компонентов кита, 19 занятых компонентов
- вид каталога «по месту»: 10 поверхностей манифеста, у пяти есть своя сцена
- тёмная тема по умолчанию; выбор человека переживает переход между страницами
- общая шапка на всех страницах: главная, стена кита, стена паттернов
- мутационный аудит гейтов: 15 статических и 2 живые мутации

### Bug Fixes

- контейнер страницы поднят до 1400 px: на 1920 оставалось по 340 px пустого поля
- сайдбар каталога 300 px от 1280, стена кита в четыре колонки от 1536, мера строки 68ch
- все страницы на одной сетке: стены кита и паттернов были на 1152 и 1024 px

- `cn` больше не гасит утилиты разных осей: `px-3 py-1.5` остаётся обоими отступами
- паспорт каталога и стена кита больше не шире экрана на 1024-1920 px и на 390 px
- со стены кита и стены паттернов снова есть выход в каталог на нужную вкладку
- числа в интерфейсе считаются из манифеста, а не пишутся словом
- пятно прожектора не заливает карточку целиком: радиус 84 px вместо 120

### Chores

- стек поднят до актуальных версий без конфликтов: Next 16.4.3, React 19.3.1, framer-motion 14.6.0,
  Tailwind 4.3.3, TypeScript 5.9.3, Playwright 1.64.1, markdownlint-cli 0.50.0
- `engines.node` приведён к требованию самого строгого инструмента: `>=22.22.2` (было `20.19.0`,
  что давало `EBADENGINE` на Node 20)
- ESLint 10, TypeScript 7 и framer-motion 15+ сознательно отложены: цепочка `typescript-eslint 8`
  требует TypeScript `<6.1`, плагины `eslint-plugin-react`/`jsx-a11y` заявляют ESLint `<=9`

### Documentation

- README приведён к шаблону `stsgs1980/webstorm-config`: бейджи, статус, скриншот стартового
  экрана, оглавление, скрипты, карта документов, архитектура, вклад, лицензия
- `docs/AUDIT.md` удалён: мутации и дыры гейтов переехали в `docs/CONVENTIONS.md`, живые замеры —
  в `REPORT.md`
- один вопрос — один документ: механика в `REPORT.md`, состав в `docs/`, правила в
